# Bachelor's Project — Early Experiments

This repository contains early experiments and learning work from the initial stage of my Bachelor's project, which later developed into an AI-based Iranian food image analysis application.

These experiments were used to explore vision-language models, understand fine-tuning workflows, and evaluate whether Llama 3.2 Vision was a suitable starting point for the project.

## Experiments

### Llama 3.2 Vision — Amazon Products Dataset

An early fine-tuning experiment using the Amazon products dataset, based on the DataCamp tutorial for fine-tuning Llama 3.2 Vision with Unsloth.

**Reference:**  
[DataCamp — Fine-Tuning Llama 3.2 Vision](https://www.datacamp.com/tutorial/fine-tuning-llama-3-2-vision)

### Radiology Mini Model

An early model setup and experimentation exercise following an online tutorial. This was part of the initial learning phase before developing the main project.

**Reference:**  
[YouTube tutorial](https://www.youtube.com/watch?v=co0lDx5J23o&t=297s)

## Relation to the Main Project

These experiments preceded the development of the main Iranian food image analysis project.

The mobile application and its backend are maintained separately in the
[`plate_calculator`](https://github.com/jewelmoradi/plate_calculator) repository.
